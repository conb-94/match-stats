# Match Stats

Match Stats shows a kids grassroots football coach, live, how long every player has been on the pitch, so game time can be shared out fairly. It also logs subs, goals and assists, and keeps season totals.

It works with no signal, and everything is saved on the phone it is used on.

## Putting it on your phone

Open the link once with signal, then add it to your home screen. After that it opens like any other app, even with no signal.

**Android (Chrome)**
1. Open the link in Chrome.
2. Tap the menu (three dots, top right).
3. Tap **Add to Home screen** (or **Install app**), then **Add**.

**iPhone (Safari)**
1. Open the link in Safari.
2. Tap the **Share** button (the square with an arrow).
3. Tap **Add to Home Screen**, then **Add**.

Open it from the home screen icon on match day, not from the browser, so your teams and matches are always in the same place.

## Backing up

Your teams, squads and matches live only on your phone. Deleting the app or clearing the browser's data would wipe them.

- **Back up:** Settings → **Back up** saves a file. Keep it somewhere safe, such as your email, Google Drive or iCloud.
- **Restore:** Settings → **Restore**, then pick the backup file. This replaces everything on the phone with what's in the file.

Back up now and then, and always before changing phones.

## For developers

- `npm test`: rules and saving tests (Node's built-in test runner)
- `npm run e2e`: builds the app and runs the browser tests (Playwright)
- `npm run build`: production build into `dist/`
- `npm run serve`: serves `dist/` on http://localhost:4173

Pushing to `main` publishes the app to GitHub Pages (see `.github/workflows/deploy.yml`).
